# research-swarm

**一套多智能体蜂群流水线：把"某个模态/器官"变成已查新、已排序、可直接开工的研究方案与实验计划——面向医学影像 AI 论文。**

经过三轮完整调研实践验证（乳腺 → 肺结节×乳腺 → 恶变预测组合）。流水线内置的检查在
任何 GPU 时间花费之前，拦截了 **8 处数据事实错误、1 处引用幻觉、3 个幻影数据集**。

[English README](README.md)

## 流水线

```
P0 目标定义(人工) → P1 文献穷尽 → P2 数据集盘点(+证伪)
  → P2.5 私有数据访谈(六问)
  → P3 思路生成(3 个主题簇智能体 × 5 轴)
  → P4 三专家评分 → [人工:选 Top-N]
  → P5 逐案查重 → [人工:继续/转向/降级]
  → P6 论文级方案 → P7 抢发窗口与竞对侦察
  → 训练端交接执行计划
```

| 阶段 | 并行度 | 产出物 | 人工门 |
|---|---|---|---|
| P0 目标定义 | — | 范围/期刊/约束 | 填写 |
| P1 文献穷尽 | 2-4 | 论文详析表+排除清单+配方归纳 | — |
| P2 数据集盘点 | 3-4 | 卡片墙+**证伪清单**+泄漏链图 | — |
| P2.5 私有数据访谈 | 人工对话 | 私有卡片+属性→价值映射 | 访谈本身 |
| P3 思路生成 | **3 起步（主题簇）** | 思路总目录 N≈12-16 | 筛不可行 |
| P4 三专家评分 | **恒 3 persona** | 排名表（均值/共识/分歧） | **选 Top-N** |
| P5 逐案查重 | **每案 1 个** | 最近邻表+三类拦截风险清单 | **继续/转向/降级** |
| P6 方案展开 | 每案 1 个 | 论文级方案（13 要素） | **立项裁决** |
| P7 窗口侦察 | 1-3 | 抢发死线+月度监测清单 | 死线签发 |

## 为什么用蜂群而不是单个智能体

- 单智能体生成的思路互相相关；三个主题簇智能体加聚合去重，覆盖面显著更宽。
- 单一专家有系统性偏置（真实案例：同一方案临床专家给 4/10、方法学家给创新 8/10）——
  三视角均值+显式分歧记录远比单专家可信。
- 查重天然可并行：一案一个自包含智能体，结论可机械合并。

## 三条铁律

1. **数据事实核查先于机制设计**。主张必须绑定已核实存在的数据字段；二手数字默认有错；
   引用幻觉零容忍；幻影数据集显式证伪。
2. **并行智能体提示词必须自包含**。智能体互相看不见——把上下文粘进每条提示词；
   扇出前统一输出 schema；写隔离（每个智能体只写自己的编号文件）。
3. **人在聚合点裁决**。Top-N 选择、查重后的继续/转向/降级、立项、死线签发——
   智能体把事实和选项做穷尽，这四个决定永远由人做。

## 亮点：私有数据访谈（P2.5）

私有数据通常在项目中途才浮现，却往往重塑整个组合。P2.5 把它设为必经阶段：
六问结构化访谈（持有性/标注/金标层级/采集协议/治理/重叠风险）+
**数据属性→研究价值映射**（病理金标→外测与审计；配对协议→协议不变性实验；
前瞻批件→前瞻臂；富集标签→标签偏移实验室……）与接入 gate
（默认仅外测；进训练需独立论证+互锁）。

```
  pipeline-prompts.md          # P0-P7 + P2.5 全部阶段提示词（{{占位符}}）
  orchestration.md             # 扇出表/共享上下文块/聚合器提示词/最小编排方案

  proposal-template.md         # 论文级方案 13 要素骨架
  experiment-plan-template.md  # 训练端交接执行计划骨架
  scoring-template.md          # 三专家评分（评分规则+schema+聚合）
  novelty-check-template.md    # 渠道记录/最近邻表/判定/风险清单
  kickoff-template.md          # 执行端开工指令

  case-structure.md            # 真实项目三件套结构（脱敏）
```

## 快速开始

- **作为技能**：clone 到你的智能体技能目录；SKILL.md frontmatter 会在
  找课题/调研/查新/实验计划/数据集盘点/自有数据 等语境下自动触发。
- **作为手册**：填 P0，然后按 `references/orchestration.md` §8.5 的最小编排方案执行——
  四批蜂群（4+3+3+5 个智能体）+ 四个人工门，每门 ≤30 分钟。
