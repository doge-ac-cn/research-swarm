# 案例结构范例：一个课题的最小文档三件套（脱敏结构说明）

真实课题（某公开基准×可微指南先验×校准方向）最终沉淀为三份互相引用的文档，
本 skill 的产出物按同一结构组织：

## 1. 论文级研究方案（权威文本）
- 题目（双轨）/摘要/gap table（8+1 行，含最新竞品增量更新）/核心贡献（标注层级）
- 方法 §（数学化到超参表）/数据表（license+泄漏链）/基线消融/指标统计/主表主图
- 时间线/风险 Plan B/投稿计划与转投链/cover letter 话术
- 角色：**方法与写作的唯一权威**，执行版与其冲突时以它为准

## 2. 查重报告
- 检索渠道与查询词逐条记录（含限流声明）/最近邻威胁排序/分要素判定/组合判定
- 差异化调整建议（论文级方案的"强制整改对照表"逐条落实它）
- 数据事实核查记录（拦截过的错误单列）
- 角色：**主张边界与合规依据**

## 3. 训练端交接执行版（自包含）
- 权限清单（可做/禁止/三停点）/下载命令与验收/方法全规格/锁定超参（硬件适配）
- 实验矩阵判据与 kill-switch/周历+GPU 协调/写作红线浓缩/周报模板
- 角色：**可转发给任何执行端开工，不依赖仓库其他文件**

## 组合层（多课题并行时追加）
- 占用边界表（谁独占什么主张，互相引用划界）
- 数据角色注册表（训练/内验/外测/审计 分区互斥，患者级）
- 发表时序（先发者被引用，后发者显式引用先发方的划分协议）

## 教训（真实发生的）
- 二手数据口径必错 → 查重阶段做字段级核实（曾拦截：双读标注不存在/数据集实为
  单标注共识集/矩阵口径写反等 8 处）
- 上游文档引用了不存在的文献 → 投稿前逐条核实作者（曾拦截 1 处引用幻觉并全局作废）
- 两个课题用同一批病例当"外部验证" → 分区锁定 + 层地图书面化
