# 多智能体编排层（fan-out / fan-in 蜂群模式）

> 实践规模参考：完整一轮 = **15 个并行智能体**（4 数据集 + 3 思路 + 3 评分 + 5 查新）；
> 查重轮最多开过 10 个并行；复评轮 3 专家 + 2 修订智能体后台并行。
> 原则：**阶段之间串行（前序产出是后序输入），阶段之内扇出并行，每个阶段末尾聚合（fan-in）**。

### 8.1 各阶段的扇出编排表

| 阶段 | 并行度 | 拆分逻辑 | 聚合动作 |
|---|---|---|---|
| P1 文献检索 | 2-4 | 按渠道拆（WebSearch 组 / OpenAlex+Crossref 组 / arXiv+EuropePMC 组 / 期刊官网组），或按子任务拆 | 去重合并（DOI 归一）→ 冲突口径标注 → 统一详析表 |
| P2 数据集盘点 | 3-4 | 按来源拆（Scientific Data 组 / TCIA 组 / Kaggle-GC-Zenodo 组 / 综述反查组） | 卡片墙合并；**证伪清单单列**；泄漏链图由聚合者统一绘制 |
| P3 思路生成 | **3 起步** | 按主题簇拆（历史实践：A 多模态与基础模型 / B 泛化与联邦·跨域 / C 工作流与可解释），每簇一个智能体各产 4-6 个思路，提示词明确"只在本簇内生成"防跨簇重复；可加第 4 个"自由交叉"智能体专攻跨簇组合 | 聚合者跨簇去重、统一 ID 编目、检查四轴覆盖缺口 |
| P4 评分 | **恒 3** | 按 persona 拆（临床/方法学/策略）——三个提示词分别投三个智能体，同一套候选 | 主持人聚合：均值、共识度、分歧、TopN |
| P5 查重 | **每案 1 个**（TopN=5 即 5 个并行） | 按方案拆——每个查重智能体只管一案，提示词自包含 | 汇总裁定表 + 三类被拦截风险清单（数据事实错误/引用幻觉/叙事撞车） |
| P6 方案展开 | 每案 1 个（5 并行） | 按方案拆 | 无需聚合（各自独立成文），但互锁条款由委托人统一签署 |
| P7 窗口/侦察 | 1-3 | 按方案或按威胁团队拆 | 启动死线对齐表 |

### 8.2 共享上下文块（每个并行智能体的提示词开头都要粘这段）

并行智能体**互相看不见**，所以每个提示词必须自包含。统一在 P0 定义一次，逐字复制进每个子智能体提示词的开头：

```
【共享上下文（所有智能体相同）】
目标：{{器官/模态/任务族}}；目标期刊：{{档位}}；硬约束：{{仅公开数据/硬件/周期}}；
已有资产与在建课题：{{列表，防撞车}}；
产出目录：{{路径}}，文件命名 = {{编号}_{类型}_{标识}.md（禁止写共享文件，聚合由主控完成）；
当前日期：{{日期}}。
```

### 8.3 聚合器提示词模板（fan-in 用）

```
你是主控聚合智能体。收到 N 份并行子报告（文件列表如下），任务：
1. 合并去重（文献按 DOI/标题归一；数据集按官方名归一；思路按主张语义去重）
2. 冲突处理：子报告间口径不一致时**不裁决、并列标注**（"来源A说X/来源B说Y，待核实"），
   裁决权在人工
3. 覆盖检查：对照本阶段应覆盖的清单，找出遗漏项（如某渠道无人认领、某数据集无卡片）
4. 统一 schema 输出（按本阶段规定的表结构）
5. 产出"差异与冲突清单"单独成节，供人工裁决
子报告：{{文件路径列表}}
```

### 8.4 蜂群运行的五条纪律

1. **自包含压倒一切**：并行智能体没有共享记忆，"见上一阶段文档"这种话必须换成把内容直接粘进提示词。判断标准：把这条提示词发给一个全新会话，它能不看任何其他文件就开工。
2. **输出 schema 前置统一**：并行前先定死表格列名和字段顺序（写进每个子提示词），聚合器才能机械合并；schema 不一致是扇出失败的头号原因。
3. **写隔离**：每个子智能体只写自己的编号文件，永远不写共享文件；聚合永远由主控/聚合器单独做——两个智能体同写一个文件必然互相覆盖。
4. **规模控制**：单阶段并行 ≤6 个（多了聚合成本反超收益）；查重按案拆是收益最高的扇出点（每案一个、互不依赖、结论可机械合并）；评分固定 3 个（persona 天然并行且必须同候选集）。
5. **人工门在阶段之间，不在阶段之内**：蜂群内部不设审批（子智能体只产草稿与事实），聚合后的统一裁决点才停下等人——否则并行优势被人等待时间吃光。

### 8.5 一轮完整调研的最小编排方案（照抄可用）

```
第1批（并行4）：P2 数据集盘点 ×3（按来源）+ P1 文献检索 ×1
  → 聚合器1：卡片墙+配方归纳
访谈步（人工）：主控向委托人提 P2.5 六问 → 私有数据卡片并入卡片墙；
  若有独有属性 → 通知第2批启用 E 轴（私有×公开组合）
第2批（并行3）：P3 思路生成 ×3（按主题簇：A 方法与模型 / B 数据与泛化 / C 场景与工作流，
  各产 4-6 个，簇内生成防重复；主题簇划分按 P1 配方归纳的当年热点调整）
  → 聚合器2：跨簇去重+统一编目（人工筛掉明显不可行的，定稿 N≈12-16）
第3批（并行3）：P4 三专家评分（同一候选集）
  → 聚合器3：评分汇总，人工选 Top5
第4批（并行5）：P5 查重 ×5（一案一个）
  → 聚合器4：查重汇总+三类拦截风险清单 → 人工裁决（继续/转向/降级）
第5批（并行5，可减为只做裁决存活者）：P6 方案展开
第6批（并行2-3）：P7 窗口+竞对侦察
全程：委托人只在 4 个聚合点出现，每次 ≤30 分钟。
```
