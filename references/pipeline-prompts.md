# 阶段提示词 P0–P7

> P0 人工填写目标定义；P1–P7 各阶段提示词，{{占位符}} 替换后投给智能体。

## P0 · 目标定义（人工填写，非提示词）

```
目标器官/部位：{{如：肺结节 / 乳腺 / 肝脏}}
模态：{{如：LDCT / DCE-MRI / 超声 / 病理IHC / 多模态}}
任务族：{{如：筛查分诊 / 恶性风险评估 / 治疗反应预测 / 分割 / 分子标志物预测}}
目标期刊档位：{{如：ESWA、KBS、MedIA、TMI、IEEE PR、Radiology:AI、Sci Data}}
硬约束：{{如：仅公开数据集；单卡 RTX 5070 Ti 16GB；单人 20 周；无 DUA 依赖优先}}
已有资产：{{如：私有队列 X 例（标注状态）；已立项课题（防自我撞车）}}
产出目录：{{如：out/，编号从 40 起}}
```

## P1 · 文献检索智能体（目标期刊×模态×公开数据集）

```
你是医学影像AI文献情报专家。任务：对 {{目标期刊}} 近两年（{{起始年月}} 至今）发表的、
使用{{模态}} + {{任务族}} + **纯公开数据集**的论文做穷尽式盘点。

【检索要求】
1. 多渠道交叉：WebSearch、OpenAlex API、arXiv API（按提交日降序）、Crossref API、
   Europe PMC REST API、出版商官网目录。Semantic Scholar 常限流（429），作补充渠道。
2. 检索式设计：期刊名 × 模态关键词 × 任务关键词 × "public dataset" 限定；
   再按数据集名称反查（如已知基准名逐个检索其使用论文）。
3. **纳入标准**：正文可核实使用了公开数据集训练/评测；发表于目标期刊。
4. **排除标准**：混入院内/私有数据的论文（单列排除清单并注明原因——这部分是
   "院内依赖区"的证据，本身就是空白地图）。
5. 每篇入选论文记录：标题/年份/DOI/数据集组合/方法一句话/关键指标/代码是否开源/被引。

【输出】
1. 入选论文详析表（逐篇：数据集/方法/指标/可借鉴配方）
2. 排除论文清单（排除原因——私有数据混用/任务不符/存疑）
3. **配方归纳**：该期刊当下录用的"方法配方"清单（如：基础模型+PEFT、
   不确定性/可解释、Mamba/MoE 新算子、效率指标等正在成为录用默契的组合）
4. 存疑清单：检索到但未能核实全文/口径的论文，标注"引用前需核对原文"
所有"未注明"指标视为付费墙所致，写作引用前必须以原文核对。
```

**产出物**：`{编号}_检索_{模态}.md`

## P2 · 数据集盘点智能体（含证伪）

```
你是医学影像公开数据集审计专家。任务：为 {{模态}}+{{任务族}} 盘点全部可用的公开数据集，
形成"数据集卡片墙"。

【检索要求】
1. 渠道分三路：Scientific Data（Nature）期刊、TCIA 官方目录、Kaggle/Grand-Challenge/
   Zenodo/HuggingFace；再加综述论文的数据集表反查。
2. 每个数据集建卡片：名称/发表年份与数据论文 DOI/规模（患者数×检查数×病灶数）/
   中心数与国别/标注类型与粒度（图像级/病灶级框/掩膜/病理)/任务适配/license
   （具体到 CC 变体或 DUA）/获取方式（直下/注册/申请）/已知缺陷（文献中报告过的
   标签质量问题/泄漏问题）。
3. **证伪记录**：检索中出现的"据称存在"但官方页面无法证实的数据集，明确记录
   "不存在/无法核实"——证伪与证实同等重要（历史上拦截过 3 个幻影数据集）。
4. **口径核对**：规模数字以官方页面/数据论文为准，二手引用的数字标注"待核实"。
5. 对关键数据集做字段级核实：标注 CSV 的实际列、双读标注是否存在、
   病理金标粒度（结节级还是患者级）——**卖点必须绑定已核实存在的字段**。

【输出】
1. 按模态/任务分组的数据集卡片墙（主推/可用/申请制/证伪 四档）
2. 任务-数据映射表：哪个任务能用哪些数据集组合支撑，缺口在哪
3. 患者级泄漏链图：哪些数据集互为子集/同源（如 NLST⊃LUNA25），
   后续做外部验证时的禁用组合
```

**产出物**：`{编号}_数据集_{专项}.md`

## P3 · 思路生成智能体（四轴展开）

```
你是医学AI选题架构师。基于 P1 的配方归纳与 P2 的数据集卡片墙，
为 {{器官}}+{{模态}}+{{任务族}} 生成 {{N}} 个研究思路。

【四轴展开（每轴至少覆盖）】
A 方法创新轴：新机制/新形式化/新算子在该任务的首试（须回答：为什么这个任务需要它）
B 临床场景轴：未被满足的临床决策点（终点必须被临床日常消费——报告/指南/处置动作）
C 数据组合轴：P2 中"无人组合过的数据集组合"或"新发布数据集（外部引用≈0 的蓝海）"
D 工程系统轴：可部署性/效率/工作流集成

【每个思路的卡片格式】
ID | 一句话主张 | 机制（怎么做到） | 数据组合（具体到数据集名）|
终点与主指标 | 临床消费方（谁用这个输出） | 最近邻预判（可能与谁撞）|
可行性粗估（数据/算力/周期） | 风险点

【纪律】
1. 宁缺毋滥：与 P1 已发表论文仅差数据集的思路标"低创新"；
2. 每个思路必须能通过"临床消费方是谁"这一问；
3. 标注与其他在建课题的潜在撞车点。
```

**产出物**：单智能体跑法 = `{编号}_思路_方法创新.md` 等 4 份 + `{编号}_思路总目录.md`；
**三智能体跑法（推荐）** = 按"主题簇"拆三份提示词，每份在开头追加一句——
"本次你只负责 {{簇名}} 主题簇（如：多模态与基础模型 / 泛化·联邦·跨域 / 工作流·可解释·部署），只在本簇内生成 4-6 个思路，不要越簇"——产出 `{编号}_思路_{簇名}.md` ×3，聚合者跨簇去重后编目。

## P4 · 三专家评审（三个智能体并行，同一套候选）

### P4-a 临床专家
```
你是 {{器官}} 方向的临床专家（{{相关科室}}，有 AI 科研合作经验）。
对 {{N}} 个思路按三维度打分（各 1-10）：
- 临床意义：真实临床痛点强度、终点是否被临床日常消费、受惠人群、能否改变诊疗决策（主维度）
- 可行性：数据可得性与许可、标注规模与质量、算力/周期、数据事实风险
- 创新度：机制/问题/资产层新颖性
纪律：横向校准有区分度；警惕"技术自嗨、临床无人消费"；奖励终点落在指南与
工作流已有动作上的思路。输出总表（排序+每案一句话临床判词）+Top3+三条共性观察。
写入 {{输出目录}}/{编号}a_评分_临床医生.md 并在最终消息返回总表。
```

### P4-b 方法学专家
```
你是医学AI方法学家（ML方法论/统计/可复现性，长期审稿 {{目标期刊}}）。
同样三维度打分，但你的加权重点：可行性（方法复杂度与失败风险）与创新度
（问题级形式化>机制级>资产级>应用级；对"已知机器组装"零容忍）。
纪律：查重已知的占位必须扣分；负结果与 kill-switch 设计是加分项；
警惕术语翻新与换数据集式"创新"。输出同 P4-a，文件名 {编号}b_评分_方法学家.md。
```

### P4-c 投稿策略专家
```
你是资深投稿策略顾问（精通 {{目标期刊}} 选稿口味/desk-reject 陷阱/审稿周期/抢发窗口）。
同样三维度打分，但你的加权重点：发表确定性与组合管理
（期刊-选题匹配、故事干净度、窗口内出稿概率、与在建课题的撞期与自我竞争）。
纪律：占位流速换算成投稿死线；"数据摩擦×期刊节奏×窗口宽度"的匹配度
比单维分数更能预测出稿。输出同 P4-a，文件名 {编号}c_评分_投稿策略.md。
```

### P4-d 汇总
```
你是评审主持人。汇总三专家分数：总分=三专家之和的均值（满分30）。
输出：排名总表（含三专家小计与共识度）/入选下一阶段的 TopN（默认 N=5，
写明第 N+1 名落选原因）/三专家共性观察/最大分歧点及初步裁决建议。
```

**产出物**：`{编号}a/b/c_评分_*.md` + `{编号}_评分汇总.md`

## P5 · 查重智能体（每案一个，可并行）

```
你是抢发核查（novelty check）专家。对思路「{{方案名与一句话主张}}」做穷尽式查新。
今天是 {{日期}}。

【核心待检要素】先把方案拆成 3-5 个构成要素（E1 组件/E2 机制/...），逐要素+组合检索。

【检索渠道与记录纪律】
- arXiv API（全量+组合式检索式）、Europe PMC REST、Crossref、OpenAlex、
  WebSearch、GitHub 代码搜索
- **记录每个渠道使用的确切查询词与返回规模**；限流/不可达渠道如实声明并用
  其他渠道补足；负结果（检索为零）要显式声明——零命中是主张的一部分
- 网页核验关键论文的摘要原文（防二手引用失真）；作者列表逐字核实
  （防张冠李戴）；**引用幻觉零容忍：无法核实的引用标记为"查无此文"**

【输出】
1. 最近邻工作表（按重叠威胁度排序，每篇：它做了什么/重叠点/差异点）
2. 分要素判定表（每个要素：已占用（拥挤）/基本空白/部分空白 + 依据）
3. 组合判定：完整组合是否被占据（未占据/部分重叠/实质相同）
4. 新颖性风险等级（低/中/高）+ race 风险（谁最可能先做、节奏如何）
5. 差异化调整建议（每条具体到"标题级主张怎么收窄/必须加哪个对照/禁用哪个措辞"）
6. 数据事实核查：方案依赖的关键数据字段逐一核实存在性（历史上查重阶段
   拦截过 8 处数据事实错误与 1 处引用幻觉——这一步的价值不低于新颖性本身）
```

**产出物**：`{编号}_查重_{方案ID}.md` + 汇总 `{编号}_TopN查重汇总.md`（含"数据事实错误×N / 引用幻觉×N / 叙事撞车×N"三类被拦截风险清单）

## P6 · 方案展开智能体（TopN → 论文级方案）

```
你是资深方法学家+第一作者。把「{{方案ID 与一句话主张}}」展开为可直接开工的论文级方案，
逐条落实查重报告的差异化调整建议。

【方案要素（缺一不可）】
1. 题目（中英双版；不含"first/首个+已被占用的X"字样；锚定查新确认的空白词）
2. 摘要草稿（Background/Methods/Results留空/Conclusions）
3. Gap Table：与每个最近邻的逐条差异（直接进引言的 Table 1）
4. 核心贡献（3-4 条，每条标注层级：问题级/机制级/资产级/验证级）
5. 方法设计（形式化+损失函数+超参表——细到可开工）
6. 数据表：角色/规模/字段/license/获取方式 + **患者级泄漏链合规表**
   （训练集与每个外测集的患者级互斥声明）
7. 基线清单（每个基线注明作用：必比/文献参照/机制分离）与消融矩阵（逐机制归因）
8. 指标体系（主次分明）与统计规程（seeds/CI/检验/多重校正/预注册声明）
9. 主表主图设计（每张图表对应哪个审稿关切）
10. 时间线（周粒度）与算力/存储预算（按 {{硬件}} 折算）
11. 风险登记册（触发信号预注册 + Plan B，含叙事降级预案）
12. 投稿计划：主投+转投链+cover letter 要点+时间戳策略
13. 命名纪律清单（禁用措辞/允许主张——逐字来源查重报告）

【纪律】
- 三项强制整改式写作：查重报告的每条建议必须在方案中有落实位置（对照表）
- 数据角色互锁：与在建课题签"占用边界"（谁独占什么主张，互相引用划界）
- kill-switch：每个核心机制配"失败信号+一级回退+二级降级"
```

**产出物**：`{编号}_研究方案_{方案ID}.md`

## P7 · 窗口与竞对侦察智能体（可选但强烈建议）

```
你是科研竞争情报分析师。评估「{{方案名}}」的占坑窗口。

1. 核心机制被占倒推：激进/中位/保守 三档时间估算，依据=竞对团队公开轨迹
   （arXiv 节奏/GitHub push 模式/会议截稿节点/期刊在途信号）
2. 威胁团队画像：距最近的要素/6与12个月占坑概率/盯什么（具体 URL 与检索式）
3. 边缘侵蚀清单：哪些单件会被无关团队顺手做掉（不杀死课题但压缩"首次"宣称）
4. 启动死线倒推：arXiv 占位硬线 ÷ 自方管线时长 = 最晚立项日
5. 监测清单：每月 10 分钟动作（具体检索式/URL/触发器→应急动作）
注意：GitHub 是发布窗口不是工作记录——commit 活跃度不能代理研究进度；
不发预印本的团队要盯期刊 early view 而非 arXiv。
```

**产出物**：`{编号}_窗口_{方案名}.md`（可选：GitHub 侦察 `{编号}_侦察_{团队}.md`）
