# 编排纪律与常见坑

1. **顺序不可颠倒**：查重（P5）必须先于方案展开（P6）的定稿——但论文骨架可在 P5 同时起步；评分（P4）必须在查重前做一次"初评"，查重后**复评**（占位发现要扣分，历史上平均降幅 −1.2/30）。
2. **数据事实核查先于机制设计**：三条被反复验证的教训——①二手口径必错（8 处数据事实错误在查重阶段被拦截）；②引用幻觉零容忍（1 处"查无此文"被拦截）；③幻影数据集要证伪（3 个不存在的数据集被标记）。
3. **评分要复评**：查重后三专家重打分，占位导致普遍降分但幅度温和；创新维度可能上升（组合完整存活时）。
4. **单维度专家会系统性偏置**：临床专家给"换算表无使用者"4 分、方法学家给同案创新 8 分——三视角均值+分歧显式记录，比单专家可信。
5. **组合级纪律**（多课题并行时）：占用边界表（谁独占什么主张）、数据角色注册表（训练/内验/外测/审计 分区互斥）、主张不重复（纪律三）、发表时序（谁先谁引谁）。
6. **常见渠道坑**：Semantic Scholar 高频 429（用 OpenAlex/Europe PMC 补）；出版商反爬（摘要经 OpenAlex 官方字段核实）；GitHub API 未认证 20 次/小时预算；付费墙致"未注明指标"——引用前必须核对原文。
7. **人工决策点**（不要让智能体自动跳过）：P4 的 TopN 选择、P5 后的"继续/转向/降级"裁决、P6 后的立项裁决、P7 的启动死线确认。

---

   智能体会把检索池期刊当投稿目标——实际出现过 J Pathol Inform（细分对口但低档）、
   CBM（2025 年已从 SCIE 除名，但模型训练数据滞后）反复入选。修复=《期刊质量控制政策》：
   目标只来自 P0 声明清单；产出物中任何期刊过"收录/风险/档位/出版商"四道检查并附查证日期；
   期刊状态是动态的，快照黑名单使用时必须复核。
