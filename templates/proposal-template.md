# 论文级研究方案模板（P6 产出，13 要素缺一不可）

> 逐条落实查重报告的差异化建议；每条整改在方案中有对照位置。

1. **题目**：中英双版；不含"first/首个+已占用X"；锚定查新确认的空白词
2. **摘要草稿**：Background / Methods / Results[待填] / Conclusions
3. **Gap Table**：与每个最近邻逐条差异（它做了什么/重叠点/本案差异）——直接进引言
4. **核心贡献**：3-4 条，标注层级（问题级/机制级/资产级/验证级）
5. **方法设计**：形式化 + 损失函数 + 超参表（细到可开工；标注硬件适配）
6. **数据表**：角色/规模/字段/license/获取方式 + 患者级泄漏链合规表（训练与每个外测集互斥声明）
7. **基线清单**：每个基线注明作用（必比/文献参照/机制分离）
8. **消融矩阵**：逐机制归因（去X→验证X的必要性）
9. **指标体系**：主次分明 + 统计规程（seeds/CI/检验/多重校正/预注册声明）
10. **主表主图**：每张图表对应哪个审稿关切
11. **时间线与预算**：周粒度 + 算力/存储（按实际硬件折算）
12. **风险登记册**：触发信号预注册 + 一级回退 + 二级叙事降级
13. **投稿计划**：主投+转投链+cover letter 要点+arXiv 时间戳策略
14. **命名纪律清单**：禁用措辞/允许主张（逐字来自查重报告）
